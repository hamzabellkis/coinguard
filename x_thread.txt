1/ 🍪 Built CoinGuard on Cookie Chain — a live wallet + network console for the SVM.

No build step. No SDK bloat. Just three files.

Here's what it does 🧵

2/ 🔌 Connect a Nightly wallet
→ see your address (linked to the explorer)
→ see your DOGE balance, live

3/ 📡 Live network panel, refreshing every 4 seconds:
• epoch + progress bar
• block height
• absolute slot
• cumulative transaction count
• node core version
• RPC calls per second

4/ ✍️ Sign a real transaction
A zero-value self-transfer that proves the full path:
sign → submit → confirm
Then it links the signature straight to the explorer.

Every failure mode gets a real message — no silent death.

5/ 💸 The part I like most:

Connecting a wallet, reading your balance, and every network stat are read-only RPC calls.

They cost nothing.

You can run this entire dashboard — connect, balance, live data — with an empty wallet.
Gas only exists if you press send.

6/ 🪙 Why Cookie Chain

Sub-second finality.
Program deploys cost about $0.05.
SPL + Token-2022 + Metaplex, standard Solana tooling.

Fast and cheap enough to actually experiment on.

7/ 🐛 Two bugs I hit that would have shipped silently:

Cookie Chain returns getBalance and getLatestBlockhash with the payload nested under `value`.
Dividing the object by 1e9 gives you NaN.
Reading blockhash off the flat shape means the transaction never sends.

Both fixed — and written up in the README.
